Conectividad y Rendimiento

Puertos y Conectividad

  • • 24 puertos 10/100/1000 Mbps con PoE
  • • 4 puertos SFP/SFP+ para fibra óptica
  • • Montaje en rack 19" (1U)
  • • Gestión vía Web, CLI, SNMP y RMON

Características Avanzadas

  • • Soporte VLAN, QoS y Link Aggregation
  • • Funciones de seguridad avanzadas
  • • Protección contra tormentas Broadcast/Multicast
  • • Soporte IGMP Snooping v1/v2/v3

Seguridad Avanzada

Incorpora potentes funciones de seguridad con vinculación IP-MAC-puerto-VID y Listas de Control de Acceso (ACL) que protegen contra ataques Broadcast Storm, ARP y DoS.

Calidad de Servicio

QoS de L2 a L4 permite gestionar mejor el tráfico de la red asegurando una transmisión de datos más fluida y rápida para aplicaciones críticas.

Gestión Completa

Interfaz de gestión vía web, CLI, SNMP y RMON para una instalación y configuración rápida, así como mantenimientos remotos.

PoE Inteligente

320W de presupuesto PoE total con soporte 802.3at/af para alimentar dispositivos como cámaras IP, access points y teléfonos VoIP.

Conectividad Flexible

4 puertos SFP para conexiones de fibra óptica de alta velocidad, ideal para enlaces troncales y conexiones a larga distancia.

Alto Rendimiento

Capacidad de switching de 56 Gbps con tabla de direcciones MAC de 16K para redes empresariales de alto tráfico.

Aplicaciones Ideales

Redes Empresariales

Ideal para oficinas y empresas que requieren un switch L2 con capacidad Gigabit Ethernet de alto rendimiento. Perfecto para conectar múltiples dispositivos de red con alimentación PoE.

Sistemas de Videovigilancia

Excelente para sistemas de seguridad IP que requieren alimentación PoE para cámaras IP. El presupuesto de 320W permite alimentar múltiples cámaras de alta resolución.

Redes Inalámbricas

Perfecto para implementar redes Wi-Fi empresariales alimentando múltiples access points. El QoS optimiza las aplicaciones de voz y video sobre la red inalámbrica.

Telefonía IP

Ideal para sistemas de comunicaciones VoIP que requieren alimentación PoE para teléfonos IP. Las características de QoS garantizan la calidad de las llamadas.
